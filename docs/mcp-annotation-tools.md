# 现有六类批注工具：实现与验证

日期：2026-09-23

## 范围与基准

用户确认本轮只完善已有的便签、高亮、矩形、箭头、手绘、图片，不增加新的批注类别，也不把本轮描述为 Acrobat 全功能复刻。已有文字页内编辑必须保持可用。

交互参考 Adobe 的批注与绘图工具说明，包括选择后编辑、外观属性、便签内容，以及普通工具创建后回到选择、手绘和高亮保持激活的行为：[4](https://helpx.adobe.com/sg/acrobat/using/commenting-pdfs.html)。本轮使用标准 PDF Text、Highlight、Square、Line、Ink、Stamp 对象保存，不把批注烘焙成页面图片。

## 已实现

| 工具 | 创建与编辑 | 绘制质量与持久化 |
| --- | --- | --- |
| 便签 | 点击添加；多行中文；双击编辑；拖动位置；改色和透明度；取消无修改 | 使用标准 Comment 图标与 Contents；提交时读取实际输入框，覆盖普通输入、粘贴和 UIA 写入路径；失败保留草稿 |
| 高亮 | 正反向文字选择；逐行预览；Ctrl 拖动区域高亮 | 后台缓存正文结构并生成 QuadPoints；忽略空白边缘的远距离吸附；区域高亮单独标记；过期预览取消，晚到结果不覆盖新手势 |
| 矩形 | 拖框；八个控制点；可选填充；实线/虚线；Shift 正方形 | 线宽以 PDF 点为单位；绘制过程中使用实际颜色、填充和透明度；靠近页边保留约束比例 |
| 箭头 | 起点、终点独立调整；Shift 约束至 45° 倍数；两端分别选择无/开放/实心箭头 | 向量预览采用与 MuPDF 标准外观相同的箭头比例；方向不因归一化矩形而反转；按实际线段及箭头轮廓命中 |
| 手绘 | 连续绘制；点、水平线、垂直线；移动与缩放 | 两轮保留端点的 Chaikin 平滑；曲线不越过原始点集的凸包；圆头、圆角；预览和 InkList 使用相同采样点，不逐段叠画出串珠 |
| 图片 | PNG/JPEG；点击或拖框放置；四角等比缩放；围绕中心旋转 90° | 保留透明背景；真实应用不透明度；移动/缩放沿用实时外观预览；文件选择取消不新建对象 |

通用属性包括六色色板、自定义颜色、HEX 输入、线宽、不透明度、填充和箭头端点样式。只有相关属性会显示。工具默认值在本次应用会话内保留；修改默认值不会反向修改已有对象。颜色和数值修改需明确点击应用。

选择框使用细蓝线、白色衬边和固定屏幕尺寸的圆形控制点。图片不显示会拉伸比例的边中点。便签不显示缩放点。文字高亮按各行显示选择提示，不使用覆盖整段空白的巨大选择框。空心矩形、箭头、手绘按实际轮廓命中，不吞掉其包围盒内的空白。

Delete 删除；Ctrl+Z / Ctrl+Y 撤销与重做；Esc 取消当前绘制并回到选择。PDF 中被锁定或只读的对象不开放修改或删除。

## 代码组织与约束

- `core/document.h`：批注样式、端点、笔画、四边形模型及文本高亮 API。
- `core/document.cpp`：标准 PDF 属性/几何读写、正文选择缓存、有效性校验、锁定检查、撤销事务与保存。
- `core/annotation_geometry.h`：平滑、点线命中、几何变换、Shift 约束及页边限制；界面与测试共享。
- `app/annotation_painter.cpp`：Direct2D 单路径向量预览，避免逐段圆帽叠画。
- `app/annotation_tools.cpp`：属性面板、工具默认值、便签编辑、创建与删除。
- `app/canvas.cpp`：六类对象选择、移动、缩放、箭头端点、取消与异步高亮预览。
- `tests/annotation_tests.cpp`：几何、外观、持久化及 UI 保存结果核验。
- `tests/canvas_tests.cpp`：画布交互及异步预览生命周期。
- `tests/annotation_smoke.ps1`：原生窗口与 UI Automation 回归；脚本带 UTF-8 BOM 以兼容 Windows PowerShell 5.1。

MuPDF 仍是固定的 1.28.4，不启用 JavaScript/OCR。所有 MuPDF 访问仍经过串行工作线程；界面线程只绘制已有几何或位图。没有修改只读的 LUMENUI 依赖源码。

界面回归曾发现：UIA 写入便签输入框不会同步触发业务层的 OnTextChanged 缓存，因此虽然显示了文字，却被误判为空。已将提交逻辑改为在对话框结果回调中读取实际输入框，并加入保存后重新打开的内容断言，避免只以屏幕显示作为通过标准。

## 验收边界

- 自动化覆盖不能替代真实鼠标/触控板手感、手写笔压感、触屏、中文输入法候选窗及跨显示器 DPI 的人工验收；本轮没有把这些列为已通过。
- 未进行安装版 Acrobat 中逐项打开、修改、再保存的互操作验收，因此不宣称与其所有版本的外观或交互完全一致。
- 使用标准 PDF 批注对象并验证本应用保存重开，不等于覆盖了所有来源 PDF 的复杂自定义外观、特殊线头、超大笔迹或损坏文件。
- 没有新增椭圆、直线、下划线、删除线、评论回复/状态、图章库、签章或协作发布体系。
- 不宣称本轮重新验收了 Word/LibreOffice 转换；相关代码没有作为本轮功能变更对象。
