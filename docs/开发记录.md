# LumenPDF 0.2

Windows 10/11 x64 本地 PDF 阅读、批注与文件整理工具。C++20 + LUMEN + MuPDF。
应用工程与旁边的 LUMENUI 保持模块分离。经用户授权，通用控件缺陷可在 LUMENUI 修复；PDF 数据、字体嵌入与文档事务仍只留在本应用。

## 运行

直接运行 **build/app/LumenPDF.exe**。同目录的 lumatext.dll 是界面文字渲染依赖，请保留。
整个便携目录可以一起移动。第一次运行无需安装；Word 转换使用本机已有 Office。
程序不联网处理文档，也不附带 Office、Python 或浏览器。

## 已实现

- PDF 连续阅读、可见区域分块渲染、缩略图、目录、搜索、复制和打开密码。
- Ctrl + 滚轮缩放；Shift + 滚轮横向浏览；支持适合页面（同时考虑宽高）。
- 文字批注单击选中、双击页内编辑，框随内容自动排版；显示态和编辑态统一使用 LumaText，框旁格式条使用 LumenUI 的字体下拉、字号、格式切换和色板，支持本机字体、粗斜体、下划线与对齐，不依赖右侧面板改文字。
- 文字框八个控制点按各自方向调整：上下改高度、左右改宽度、四角同时改宽高；手调尺寸保存重开后保留。便签、高亮、矩形、箭头、手绘和图片批注继续可用。
- 多选页面、旋转、删除、拖动重排、插入空白页或 PDF、提取页面。
- 撤销、重做、另存为；普通保存保留批注可编辑性。
- PDF、DOC/DOCX、TXT、PNG/JPEG 混合合并；文件拖放和重排、页码范围、密码、编码选择、预览和导出。
- 合并队列按 PDF、Word、文本、图片区分图标；副行显示页码和处理状态。转换、按页合并、写入校验分阶段显示当前文件、进度和耗时，支持取消。
- 合并会固化来源批注和表单外观，保留正文文字、矢量与图片，并按文件名建立一级目录。
- Word 优先转换；可选择已安装的 LibreOffice，或用 LUMENPDF_LIBREOFFICE 环境变量指定 soffice.com。
- 转换辅助进程支持取消及 120 秒超时；Word 禁用宏和打开时更新链接，仅关闭本程序创建的实例。
- 保存先写临时文件，子集化嵌入字体、验证可重新打开，再原子替换目标。
- 编辑期间每 60 秒自动备份；异常退出后下次启动可恢复最近备份。正常退出删除本次备份。

## 常用操作

1. 点击“打开”（可多选），或把文件拖到文档区，每个文件进入独立标签；只有“合并”工作区的拖入文件进入合并队列。
2. 在“批注”选择“文字”，点空白或拖框输入；点已有文字直接编辑，选择工具下也可双击。字体与格式在文字框旁修改。Enter 换行，点击页面空白或 Ctrl+Enter 完成，Esc 取消草稿。手调框不会自动缩回；溢出时可点“适合文字”。提交一次编辑只占一步 PDF 撤销；编辑中的 Ctrl+Z/Y 操作文字输入。
3. 批注工具栏的“签名”：选择已保存的签名、今天日期或 ✓ / ✗，单击页面放置（拖框指定大小，按住 Shift 连续放置，Esc 取消）；也可在此手写、输入文字或从图片导入新签名。
4. Esc 返回选择工具。空白处拖出矩形后，区域内可提取的文字会复制到剪贴板。
5. “页面”以网格显示全部页面缩略图：Ctrl / Shift 多选，拖动任一缩略图（或一组选中页）到新位置重排，Esc 取消拖动，双击在阅读视图打开，Ctrl + 滚轮调整缩略图大小；左侧缩略图栏也可直接拖动重排。重排、删除和旋转都可以撤销。
6. “合并”中拖入文件、调整顺序。点击一行可填写 1-3,5 这样的范围；范围按转换后的页码计算。
7. 先“生成预览”检查分页、字体和表格，再另存为；也可以“合并并导出”。

快捷键：Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+F 搜索，Ctrl+Z/Y 撤销/重做。

自动备份位置：%LOCALAPPDATA%/LumenPDF/Recovery。最多可能丢失最后约一分钟尚未备份的编辑；未及时完成的备份不替代手动保存。
备份保留原 PDF 的打开密码，程序不保存密码到设置文件。

## 版本边界与待验收项

这是可以试用的首版，不是已经通过全部真实文件验收的正式版。

- 不提供原有段落重排、OCR、Word 编辑或表单填写。
- 现有七类批注均可使用；六类非文字工具与新增文字格式均采用可编辑 PDF 批注。旋转过的文字批注暂不支持页内编辑。
- 不保证合并后保留内部跳转、原目录、交互表单和数字签名有效性。
- 单个直接打开的输入文件上限为 1 GiB；不保证所有复杂或损坏 PDF 都能正常处理。
- 搜索界面展示上限为 20,000 条并显式提示；核心不再采用单页 256 / 全文 5000 截断。详见文末本批升级说明。
- 新增文字默认微软雅黑，可改为本机已安装且许可允许可编辑嵌入、子集化的字体；不支持直接导入外部字体文件。格式按整条批注应用，不是选区混排富文本。
- 缺字时会使用字体回退，Windows 编辑预览与 MuPDF 的回退可能不同；复杂脚本与特殊字体不声明像素级一致。
- 本机 Word 转换已实测；LibreOffice 路径已实现，但当前机器未安装，尚未实测。
- 当前 150% DPI 的四个工作区已完成截图自检；真实鼠标拖动手感、中文输入法和跨显示器 DPI 切换仍需人工验收。
- 保存失败和取消保留原文件已有自动化测试；真实断电、磁盘耗尽、大型扫描件长时间压力测试尚未完成。
- 自动恢复快照已测试；强制结束进程再恢复的完整界面流程尚待实机验收。

## 0.2.1 批注拖动实时跟随

拖动或缩放文字批注时，文字随边框实时移动，不再等松开鼠标才同步。实现方式：按下时后台渲染该批注的透明外观位图（`Document::RenderAnnotation`），同时页面瓦片改为隐藏该批注重新渲染；两者都就绪后切换为“隐藏瓦片 + 跟随位图”，之前保持原图不闪。松开后本地立即按新位置显示，文档更新完成、新瓦片到齐后位图自动退场；期间旧瓦片继续垫底，不再整页闪白。图片批注拖动缩放时位图随框等比拉伸；文字批注只平移，缩放时裁剪显示，松开后由 MuPDF 按新宽度重新排版。

验证：pdf_core 新增单批注外观渲染断言（透明背景、不改动文档、不增加撤销步）；canvas_interactions 新增拖动预览生命周期（按下请求位图与隐藏瓦片、跟随、落下提交、新瓦片到齐后退场）；tests/drag_smoke.ps1 在真实程序中发送鼠标消息，截取拖动中、松开后 20/60/120/250/500 ms 与稳定后的画面，已核对全程文字与边框一致、原位无残影。真实鼠标手感与高 DPI 多屏仍需人工验收。
## 0.2.2 现有六类批注工具完善

本轮只完善原有便签、高亮、矩形、箭头、手绘、图片工具，不扩展图章库、审阅回复或云协作体系。

- **便签**：点击添加、多行评论、双击编辑、拖动位置、颜色与透明度；取消或提交空的新便签不改变文档。
- **高亮**：沿文字拖动，后台计算逐行 QuadPoints，预览与提交使用相同选择端点；反向选择可用。按住 **Ctrl** 拖动可对扫描件或图片做区域高亮，不再把空白处拖动误吸附到远处文字。文字高亮保留逐行结构，不开放自由缩放；区域高亮可调整范围。
- **矩形**：精细边线、可选填充、实线/虚线；按住 **Shift** 绘制正方形，靠近页边仍保持比例。
- **箭头**：方向跟随鼠标，两个端点分别编辑；**Shift** 限制为 45° 的倍数。起点和终点可分别设置无箭头、开放箭头、实心箭头。
- **手绘**：保留端点的平滑处理、圆头圆角；预览与保存使用相同路径。支持点、水平线、垂直线与连续绘制。
- **图片**：PNG/JPEG、保留透明背景、等比例放置、四角缩放、围绕中心旋转 90°，透明度会真实影响渲染，不只是修改元数据。

右侧面板可调整颜色、线宽、不透明度及工具特有属性；选工具但未选对象时，“设为新建属性”只改变当前会话的工具默认值。点击色块或调色后需应用属性。普通选择依照线条、路径或逐行高亮区域命中，不会用箭头的大包围盒遮住空白。选中批注后按 **Delete** 删除，**Ctrl+Z / Ctrl+Y** 撤销/重做，**Esc** 取消当前绘制并回到选择。手绘和高亮完成后保持选中，其他工具完成后回到选择。

构建：`build.bat`。新增回归：`annotation_tools`；原有 `pdf_core` 和 `canvas_interactions` 同时保留。原生界面测试：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/annotation_smoke.ps1`，截图与临时 PDF 写入 `build/app/annotation-output/`。该脚本只操作自己启动的测试实例和测试副本。

## 0.3 阅读器基础（2026-09-23）

- **页面链接**：目录页码和正文里的内部链接，单击后跳到目标页（有目标位置时滚到该处）。鼠标悬停时光标变成手形，链接下方出现下划线，状态栏显示目标。外部链接只打开 `http(s)`、`mailto`，打开前会先确认。`file:` 等其它协议一律拒绝。
- **返回/前进**：跳链接、点目录前的位置会记下来，按 `Alt+←` / `Alt+→` 可以回去，右键菜单里也有“返回上一位置”。

## 设为默认阅读器的稳定性与右键图标（2026-09-23）

**崩溃原因**
- 旧做法在界面线程上调用 `SHOpenWithDialog`（“选择打开方式”窗口）。它会在调用线程上跑自己的模态消息循环。
- 设置对话框刚关闭，界面就在这个嵌套循环里重入绘制，访问了已释放的对象，导致 0xC0000005 崩溃。
- 崩溃转储的栈中有 shell32 和 user32 的嵌套消息分发，与此吻合。

**现在的做法（微软推荐）**
- 程序在 `Software\RegisteredApplications` 和 `Capabilities\FileAssociations` 中登记，然后打开 `ms-settings:defaultapps?registeredAppUser=LumenPDF`，由用户在系统设置里确认。
- Windows 11 23H2 及以上，以及安装了 2023-04 更新的 21H2/22H2，会直接定位到“应用 > 默认应用 > LumenPDF”页面。
- 打开系统设置放在独立线程执行，界面不等待。
- 从确认框或设置对话框触发时，先 Post 到下一轮消息再执行。
- 打开设置后，每 1.5 秒检查一次，最多 2 分钟。用户选好后，按钮和提示自动更新，不需要重启程序。

**右键菜单图标**
- 资源管理器 verb 的 `Icon` 值写成带引号的 `"C:\…\LumenPDF.exe",0` 时，经典右键菜单不显示图标。现在改为写不带引号的路径。
- 启动时自动修复会把旧的带引号值视为需要修复，自动改写。

- **页眉页脚、页码与水印…**：页码样式预设、`{page}` `{total}`、起始页码、左/中/右对齐、字号、页面范围；水印可调不透明度、角度，可置于内容下方。写入页面内容（表单 XObject，原内容包在 q/Q 中），一次可撤销。
- **编辑书签…**：目录侧栏底部工具条：在当前页添加、重命名、删除（含子书签时确认）、同级上移/下移、升级/降级，以及“拖动整理”模式（平铺列表、按层级缩进、拖动整棵子树）。每次修改一次可撤销；指向外部链接的书签无法按页编辑，修改前会提示。

**修复**：MuPDF 会按摘要缓存已嵌入的字体对象，撤销后缓存仍指向已删除的对象，再写入印章/页眉时会引用不存在的对象。现在撤销、重做、放弃操作和生成新内容前都会清空该缓存。

**测试**：pdf_core 新增新批注往返、印章改字、压缩、三种拆分及非法参数、页眉页脚/水印（文字、页码、范围、撤销、保存重开）、书签（层级/位置往返、撤销、清空）；新增 `tests/feature_smoke.ps1`（真实窗口：画椭圆/直线、印章对话框、添加书签、页眉页脚+水印、单页拆分提示、压缩另存，保存后用 `annotation_tests --verify-features` 校验原文件与压缩副本）。

## 文件类型配色、平移范围与合并提速（2026-09-24）

- **文件图标配色**：合并列表和主页“最近打开”行里，PDF 红、Word 蓝、TXT 浅灰、图片绿，图标下衬同色淡底块（`ui::FileColor` / `ui::DrawFileIcon`）。丢失、加密的文件仍显示灰色警告/锁图标。

- **合并/保存提速**：保存的“整理”一步原来用 MuPDF 垃圾回收级别 3，其中“去除重复对象”要两两比较全部对象（O(n²)，且反复多轮）。现在对象数超过 4000 的文件改用级别 2（回收 + 压缩编号，线性），小文件仍去重；字体子集化照常。实测 `地基承载力修正计算.pdf + 基础图形结果.pdf + 上部图形结果.pdf`（115 页，27 MB）：这一步从 562 秒降到 1.9 秒，整次合并从 569 秒降到 7.7 秒，输出只大 15 KB（0.06%）。基准命令：`build\app\merge_tests.exe --bench-merge 输出.pdf 输入1.pdf 输入2.pdf …`；设置环境变量 `LPDF_DEDUPE_LIMIT` 可临时改阈值做对比。

构建注意：本机 Ninja 没有记录任何头文件依赖（`ninja -t deps` 显示 `#deps 0`），原因是 CMake 生成的 `msvc_deps_prefix` 与 cl 实际输出的中文“注意: 包含文件:”编码不一致，这些行也因此出现在构建输出里。结果是只改头文件时，包含它的 .cpp 不会重新编译，可能产生成员偏移不一致的崩溃。改动头文件后，请删除相关 .obj 或整体重新构建；也可以在配置前设置 `VSLANG=1033`，让 cl 输出英文前缀。

## 真正的涂黑（安全遮盖，2026-09-28）

“裁剪”和盖一个黑色矩形批注都**不能**真正隐藏内容（文字仍可复制、搜索）。涂黑会把标记区域下的内容从文件中永久删除：

- **进入**：更多 → 文档工具 → **涂黑（永久删除内容）…**。页面上拖动框选要删除的区域；单击标记（或悬停后按 Delete）删除标记；Esc 退出。
- **按文字标记**：选中文字后右键 → **涂黑选中文字**；搜索后 更多 → **涂黑全部搜索结果**（重复标记自动去重）。
- **预览**：标记显示为半透明黑块 + 红框，下方内容仍可辨认，便于核对位置。标记只存在于程序中，文档本身不变；页数或页面尺寸变化（插入 / 删除 / 旋转 / 裁剪页、切换文档）后标记自动清除。
- **应用**：更多 → **应用涂黑并另存副本…**，可选：与涂黑区相交的图片整张删除（默认只涂黑被覆盖的像素）、删除被完全覆盖的线条与形状（默认开）、清除文档属性（标题 / 作者 / 主题 / 关键词 / 创建程序与 XMP，默认开）。结果**只能另存为新文件**（不能覆盖原件），当前文档和原文件都不改动。
- 删除的内容：区域内的文字（包括扫描件 OCR 的隐藏文字层）、被覆盖的图片像素、被覆盖的图形；与区域重叠的批注及其弹出注释被删除；重叠的表单字段被清空值、默认值与外观并隐藏锁定。输出做完整重写与垃圾回收，被删除的对象不会残留在文件中。
- **校验**：发布前重新打开副本，逐个标记检查区域内是否残留可提取文字；有残留则报错且不生成文件。

### 限制

- 书签标题、附件、页面标签、结构树中的替代文字等**不在页面区域内**的内容不会自动删除；如含敏感信息，请另行删除书签 / 附件。
- 涂黑按矩形区域处理：与区域有任何重叠的整个字形都会被删除（可能多删相邻半个字）；被覆盖的线条只在完全覆盖时删除。
- 这是 MuPDF 的内容级涂黑，不是 Adobe “清理文档”的全部功能（如隐藏图层、JavaScript 清理）。

### 实现

- `core/document.*`：`ApplyRedactions`（`pdf_redact_page`，黑块、图片像素 / 整张、线稿、文字全删；重叠批注 / 弹出注释 / 表单处理；元数据清理）与 `ExportRedacted`（快照 → 副本涂黑 → `Save` 完整重写与垃圾回收 → 重新打开校验 → 原子替换目标文件）。
- `app/canvas.*`：涂黑模式的框选（限制在起始页内）、命中、悬停 ×、Delete / Esc，与其它工具互斥。
- `app/redaction_tools.cpp`：标记管理、菜单 / 右键入口、应用对话框、另存与打开副本、自动化冒烟。

### 验证

## 临时视图旋转（2026-09-28）

- 需要永久生效：右键「按此方向旋转页面（写入文件）」，走普通的页面旋转（可 Ctrl+Z 撤销），之后视图自动归零、画面方向不变。

- 视图状态 `ViewState` 增加 rotation。

## 框选放大与放大镜（2026-09-28）

## 朗读（2026-09-28）

用 Windows 自带语音朗读 PDF 正文，不联网：

- **Ctrl+Shift+V** 朗读本页，**Ctrl+Shift+B** 从本页朗读到文末，**Ctrl+Shift+C** 暂停 / 继续，**Ctrl+Shift+E** 或 **Esc** 停止（快捷键与 Acrobat 相同）。
- 右键菜单：朗读本页；有选中文字时「朗读选中文字」；朗读中「停止朗读」。更多菜单 →「朗读」一组，以及「朗读控制与设置」：上一句 / 下一句、语速（很慢 / 慢 / 正常 / 快 / 很快）、声音。
- **跟读**：当前句淡绿底 + 下划线；句子不在视口内时自动滚过去并更新页码。状态栏显示页码、第几句、所用声音与语速。
- **声音**：默认「自动」——含中文的句子用中文语音，其它用英文语音；也可指定某个已安装的语音。除桌面 SAPI 语音外，还会列出 Windows 10/11 自带的 OneCore 语音（如 Kangkang、Yaoyao）。语速和声音记在设置里。
- 朗读到文末时，没有文字层的页面（空白页、扫描件）自动跳过；单页朗读遇到这种页面会提示「需要先识别文字」。
- 切换或关闭文档时自动停止。只读取文字，不修改文件。

### 实现
- `core/document`：`ReadingSentences(page)` 在文字选择所用的同一份 stext 上按阅读顺序断句：中文 。！？；…、英文 . ! ? ; 后跟空白（小数点不断），后引号 / 括号随句；段落按「新块且行距变大 / 回到上方另起一栏 / 首行缩进」判断（有的 PDF 每行一个块），其余换行视为续行（英文补空格、行尾连字符合并）；过长的句子在逗号处再切；每句带逐行包围框。
- `app/speech`：`SpeechPlayer` 在独立线程持有 SAPI `ISpVoice`，一次说一句（`SPF_ASYNC` + `WaitUntilDone` 轮询，暂停 / 跳句 / 停止即时生效），session 号丢弃过期回调；`InstalledVoices` 枚举桌面与 OneCore 语音；可输出到 WAV（测试用，不出声）。
- `app/read_aloud.cpp`：取文字走引擎线程，界面线程编排跟读、翻页、状态栏与菜单；`app/canvas` 增加跟读高亮 `SpeechHighlight`。

### 验证
- `read_aloud`（48 项）：真实 PDF 断句（中英文、续行连字符、小数点、逐行框、阅读顺序、空白页）、纯文字断句、语音枚举（本机 4 个：Huihui、Zira、Kangkang、Yaoyao，**全部实际合成成功**）、自动选语音（中文句用中文语音）、顺序、跳句、暂停不前进、继续、停止后无回调、越过末尾结束。
- `read_aloud_ui`：真实程序从第 1 页读到文末（4 页，跳过空白的第 2 页）、跟读高亮、自动翻到最后一页、暂停 / 继续、跳句、停止后高亮清除，文件未变脏。
- `canvas_interactions`（总 336 项，新增 8 项）：跟读高亮保存 / 清除、已可见不滚动、不跟随时不滚动、不可见时滚入视口并更新页码、越界忽略、换文档清除。
- 截图核对跟读高亮与状态栏。**所有自动测试的语音都写入 WAV 文件，没有在电脑上发出声音。**
- **未测试**：实际扬声器播放的听感（测试只写文件）；多栏排版 / 竖排中文的断句顺序；超长文档连续朗读的稳定性；朗读中编辑文档（页面增删后句子位置可能对不上，建议先停止）。
